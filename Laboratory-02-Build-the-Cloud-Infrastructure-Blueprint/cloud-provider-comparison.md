# Major Cloud Provider Infrastructure Services Comparison

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 / EBS | Azure Blob Storage / Managed Disks | Cloud Storage / Persistent Disk |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | VPC Service Controls |
| **Identity & Access (IAM)**| AWS IAM | Microsoft Entra ID (Azure AD) | Cloud IAM |

---

### Analysis Questions

**1.** Amazon Web Services (AWS) offers the broadest range of cloud services, boasting over 200 fully featured offerings globally. AWS achieved early market dominance, which allowed it to develop deeper, highly specialized catalog depth in compute, database, and operational tooling.

**2.** Microsoft Azure is recommended because it provides native integration with active enterprise directory management via Microsoft Entra ID (formerly Azure AD). Organizations can seamlessly leverage existing Windows Server licenses, Microsoft 365 integrations, and active enterprise agreements.

**3.** Google Cloud Platform (GCP) is widely recognized in these sectors due to its pioneering work developing Kubernetes and open-source TensorFlow frameworks. GCP’s Vertex AI platform and Google Kubernetes Engine (GKE) offer market-leading, deeply integrated container orchestration and model-training tools.

**4.** All three providers follow the exact same architectural paradigms for core IaaS infrastructure, matching feature-for-feature across compute, block/object storage, private virtual networks, and role-based IAM. They also enforce shared responsibility security models, dynamic pay-as-you-go billing, and multi-region availability zones.
