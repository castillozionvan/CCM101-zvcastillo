# System Baseline Report

## Host System Specifications

* **Total Available RAM:** 1.2 GiB 
* **Total Root File System Storage Capacity (`19`):** 13 GiB
## Critical Resource Analysis

Checking available disk space prior to a massive traffic surge is critical because web servers continuously generate access logs, error logs, and temporary cache files during high traffic; running out of disk space will cause log writes to fail and lead to server crashes.
