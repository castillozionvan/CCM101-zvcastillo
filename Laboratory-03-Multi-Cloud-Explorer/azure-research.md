# Azure Research Report: Microsoft Azure

![Azure Homepage](screenshots/azure-homepage.png)

## Brief Overview
Microsoft Azure, launched in 2010, is an enterprise public cloud platform offering over 200 cloud products and services. It allows organizations to build, deploy, and manage applications across a global network of data centers, making it a trusted platform for enterprise innovation.

## Global Infrastructure
Azure features a massive cloud footprint designed for reliability and compliance:
* **Azure Regions:** Geographically defined areas containing one or more physical data centers connected through a dedicated low-latency network.
* **Availability Zones:** Physically separate data center locations within a region featuring independent power, cooling, and networking.
* **Geographies:** Regional boundaries containing multiple regions that preserve data residency limits for legal compliance.

## Cloud Management Console
The **Azure Portal** serves as a unified web-based administration console:
* Built on a dynamic blade-based navigation layout to manage complex enterprise workflows.
* Includes embedded **Azure Cloud Shell** supporting both Bash and PowerShell environments.
* Offers resource group management to organize billing and permissions cleanly.

## Four (4) Core Services
* **Azure Virtual Machines:** Scalable virtual compute instances running Windows Server or Linux distributions.
* **Azure Blob Storage:** Massively scalable object storage designed for unstructured data such as files, logs, and media.
* **Azure Virtual Network (VNet):** Private network building block enabling secure communication between Azure resources.
* **Microsoft Entra ID (formerly Azure AD):** Cloud-based identity and access management service for single sign-on (SSO) and authentication.

## Three (3) Key Advantages
* **Seamless Microsoft Integration:** Native compatibility with Windows Server, Active Directory, SQL Server, and Microsoft 365.
* **Hybrid Cloud Leadership:** Strong hybrid deployment capabilities enabling unified management via Azure Arc.
* **Enterprise Licensing Discounts:** Azure Hybrid Benefit savings when transferring existing Microsoft licenses to the cloud.

## Typical Enterprise Use Cases
* Extending on-premises Active Directory into hybrid cloud environments.
* Hosting enterprise .NET software stacks and Windows Server applications.
* Migrating on-premises SQL Server databases to managed cloud databases.
