# GCP Research Report: Google Cloud Platform

![GCP Homepage](screenshots/gcp-homepage.png)

## Brief Overview
Google Cloud Platform (GCP), introduced in 2008, is a modular suite of public cloud computing services running on the same global infrastructure Google uses internally for products like Search and Gmail. GCP is widely recognized for its strengths in high-performance computing, data analytics, container orchestration, and artificial intelligence.

## Global Infrastructure
GCP is built on Google's private global fiber backbone network:
* **Regions:** Independent geographic locations hosting cloud resources.
* **Zones:** Deployment locations within a region representing isolated fault domains.
* **Points of Presence (PoPs):** Network edge nodes delivering low-latency connections worldwide.

## Cloud Management Console
The **Google Cloud Console** offers a developer-focused user interface:
* Structured strictly around **Projects** for isolated resource tracking and access delegation.
* Built-in **Google Cloud Shell** with pre-configured developer tools and the `gcloud` CLI.
* Integrated Google Cloud Observability suite for real-time monitoring and logging.

## Four (4) Core Services
* **Compute Engine:** High-performance, customizable virtual machine instances running on Google infrastructure.
* **Cloud Storage:** Durable, unified object storage for live data access and long-term archiving.
* **Virtual Private Cloud (VPC):** Global virtual networking providing secure private connectivity across regions.
* **Cloud IAM:** Granular identity and access management for authorizing actions on GCP resources.

## Three (3) Key Advantages
* **Containerization Leader:** Original creator of Kubernetes, offering advanced cluster management via Google Kubernetes Engine (GKE).
* **Advanced AI & Data Analytics:** High-performance tools like BigQuery data warehouse and Vertex AI machine learning ecosystem.
* **High-Speed Global Network:** Traffic moves directly across Google’s fast private global fiber network.

## Typical Enterprise Use Cases
* Big data processing and real-time streaming pipelines via BigQuery.
* Training and deploying Machine Learning / Generative AI models using Vertex AI.
* Managing cloud-native microservices architectures on Kubernetes clusters.
