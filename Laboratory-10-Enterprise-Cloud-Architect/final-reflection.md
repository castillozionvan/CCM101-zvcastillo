# Final Reflection – Laboratory Activity 10

---

Wrapping up Laboratory 10 really brings full circle everything I’ve worked on in this course. Looking back at where I started in Lab 1—just trying to get comfortable with basic Linux terminal commands—to where I am now, building out a full multi-tier cloud setup as an Enterprise Cloud Architect, the growth in both my technical skill and confidence has been huge.

For this final project, I set up a complete Nextcloud and MariaDB stack from scratch. I made sure data would persist across container restarts using dedicated volumes, hardened the server using UFW with a strict Default Deny policy, and wrote a Bash script paired with a daily Cron job to handle disaster recovery automatically. It forced me to pull together everything we covered throughout the term—Linux system administration, Docker containerization, stack security, and automation—into one unified system.

It wasn't completely smooth sailing, though. I ran into my fair share of annoying YAML indentation bugs and Docker permission errors along the way. But working through those hiccups actually taught me the most about systematic debugging and paying attention to detail. It also made me realize that being a cloud architect isn't just about spinning up containers—it's about writing clean documentation, securing your setup, and taking full ownership of your infrastructure.

Seeing all ten completed laboratories sitting in my GitHub repository feels really rewarding. It's a clear record of how far I've come since the start of the semester, and I feel a lot more prepared to tackle real-world IT and cloud engineering challenges moving forward.
